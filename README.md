# เปรียบเทียบใบหน้า (Face Compare)

เว็บแอปเปรียบเทียบใบหน้าบุคคล A และ B ใช้ได้ทั้งบน iPhone (Safari) และคอมพิวเตอร์

- อัปโหลด/ถ่ายภาพ A และ B (JPEG, PNG, WebP, HEIC; หมุนตาม EXIF อัตโนมัติ)
- ตรวจจับใบหน้าและจัดตำแหน่งอัตโนมัติ (SCRFD + จุดอ้างอิง 5 จุด); ภาพกลุ่มเลือกใบหน้าได้โดยแตะกรอบ
- คะแนนความคล้าย (cosine similarity × 100, ArcFace w600k_r50) พร้อมระดับ และการเตือนคุณภาพภาพ (เล็ก/เบลอ/มืด/หันข้าง ฯลฯ)
- เปรียบเทียบเคียงข้าง, เลื่อนเทียบ (wipe), ซ้อนโปร่งแสง และเทียบเฉพาะส่วน (ตา/จมูก/ปาก)
- ออกรายงาน PDF ภาษาไทย: ภาพต้นฉบับพร้อมกรอบ, ใบหน้าที่จัดตำแหน่ง, คะแนน, คุณภาพภาพ, SHA-256 ของไฟล์, วิธีการ, ข้อควรระวัง, ช่องลงนาม

> **ข้อสำคัญ** คะแนนความคล้ายไม่ใช่เปอร์เซ็นต์ยืนยันว่าเป็นบุคคลเดียวกัน โดยเฉพาะงานสืบสวน
> ต้องให้ผู้เชี่ยวชาญตรวจสอบและใช้หลักฐานอื่นประกอบ — ข้อความนี้แสดงในหน้าผลลัพธ์และในรายงาน PDF ทุกฉบับ
> เกณฑ์ระดับ (ต่ำมาก <20 · ต่ำ 20–30 · ก้ำกึ่ง 30–40 · สูง 40–55 · สูงมาก ≥55) เป็นแนวทางทั่วไป
> ไม่ได้สอบเทียบกับข้อมูลของคุณ ปรับได้ที่ `app/config.py` (`BANDS`)

## วิธีรัน

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python scripts/download_models.py          # โหลดโมเดล (~280 MB) ครั้งแรกครั้งเดียว
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

เปิด <http://localhost:8000> บนคอมพิวเตอร์

**ใช้บน iPhone:** ให้ iPhone และคอมพิวเตอร์อยู่ Wi-Fi เดียวกัน แล้วเปิด `http://<IP ของคอมพิวเตอร์>:8000` ใน Safari
(ปุ่ม "ถ่ายรูป" เปิดกล้องได้โดยตรง; ไม่ต้องใช้ HTTPS) หากจะเปิดให้เข้าจากอินเทอร์เน็ต ควรวางหลัง HTTPS reverse proxy และใส่การยืนยันตัวตน เพราะระบบนี้ไม่มีระบบผู้ใช้

หรือใช้ Docker: `docker build -t face-compare . && docker run -p 8000:8000 face-compare`

## ความเป็นส่วนตัว

ภาพถูกเก็บในหน่วยความจำของเซิร์ฟเวอร์ชั่วคราว (สูงสุด 24 ภาพ, หมดอายุใน 30 นาที) ไม่เขียนลงดิสก์
กด "เปลี่ยนภาพ"/"ล้างทั้งหมด" เพื่อลบทันที

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `app/engine.py` | ตรวจจับ/จัดตำแหน่ง/ฝังเวกเตอร์ (ONNX Runtime) และประเมินคุณภาพ |
| `app/service.py` | แคชภาพชั่วคราว, ตรรกะการเปรียบเทียบ |
| `app/report.py` | สร้าง PDF (ReportLab, ฟอนต์ Sarabun, ตัดคำไทยด้วย pythainlp) |
| `app/main.py` | FastAPI: `/api/upload`, `/api/compare`, `/api/report` |
| `app/static/` | หน้าเว็บ (HTML/CSS/JS ล้วน ไม่ต้อง build) |

## ข้อจำกัด / สิทธิ์การใช้งาน

- โมเดล InsightFace (buffalo_l) เผยแพร่เพื่อ **การวิจัย/ไม่ใช่เชิงพาณิชย์** — ตรวจสอบสิทธิ์ก่อนใช้งานจริง
- ความแม่นยำลดลงมากเมื่อภาพเบลอ หันข้าง ใส่หน้ากาก/แว่นดำ แสงต่างกันมาก หรืออายุต่างกันมาก
- ฟอนต์ Sarabun อยู่ภายใต้ SIL OFL (ดู `app/fonts/OFL.txt`)
